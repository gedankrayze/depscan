# DepScan v3.0.2

This maintenance release updates dependencies and makes build-artifact snapshot
exclusions part of contributor setup. CLI commands, JSON schema 4, public Rust
time types, Rust 1.96.0 support, and the five-target/16-file release contract remain.

## Project setup and Git snapshots

- Install the marked build rules from `.gitignore` into Git's local `info/exclude`
  file through `python3 scripts/setup-project.py` (DS-129).
- Run setup automatically in every development gate and trusted Codex session.
  Preserve existing local entries, avoid duplicate rules, and share exclusions
  correctly across linked worktrees.
- Keep root and nested `target/` directories, Rust backup files, and debug symbols
  out of ordinary Git-based snapshots even when switching to an older branch
  without `.gitignore`. Git protects the initial clone through the tracked ignore
  file; it does not execute setup automatically during cloning.
- Exercise fresh-clone snapshots, source preservation, repeated setup, existing
  exclusion bytes, linked worktrees, lock contention, external symlink refusal,
  and visible session-hook failures.

Ignore rules do not prevent explicit force-adds or exclude files already tracked
by Git. Existing unreachable snapshots require separate, scoped Git maintenance.

## Dependencies

Process incoming PRs #98–101 and align stable workspace requirements to Clap
4.6.10, Jiff 1.0.3, TOML 1.2.3, and SHA-2 0.11.2 (DS-130). Refresh compatible
transitive dependencies including async-compression 0.4.54, h2 0.4.21, zerocopy
0.8.66, and zlib-rs 0.6.9. Retain the patched Tokio/Rustls floors and eMudhra
intermediate-key distrust protections. Older transitive dependency families remain
bounded by their upstream owners; no global overrides or advisory ignores are added.
