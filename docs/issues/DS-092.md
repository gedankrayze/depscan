# DS-092: Add a SECURITY.md vulnerability disclosure policy

- **Status:** Open
- **Priority:** P2
- **Scope:** Repository hygiene

## Evidence

- The 2026-08-21 review found no `SECURITY.md` in a repository that ships a security tool with
  hardened release, attestation, and capability-safety machinery. There is no documented private
  reporting channel or supported-version statement.

## Acceptance criteria

- `SECURITY.md` names the private reporting channel (GitHub private vulnerability reporting or a
  maintainer address), expected response window, and which release lines receive fixes; the
  README links to it.

## Verification

- GitHub's Security tab picks up the policy; `bash scripts/dev-gate.sh quick` for repository
  checks.
