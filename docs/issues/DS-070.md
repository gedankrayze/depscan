# DS-070: Make transport retry tests platform-semantic

- **Status:** In progress
- **Priority:** P1
- **Scope:** Provider retry tests / native Windows portability

## Evidence

- Native Windows jobs
  [96362737605](https://github.com/gedankrayze/depscan/actions/runs/32348643782/job/96362737605)
  and
  [96362750292](https://github.com/gedankrayze/depscan/actions/runs/32348647600/job/96362750292)
  both recorded all three expected retry sleeps for an unavailable endpoint, then failed only the
  assertion that its terminal detail must contain `connection failed`.
- Production deliberately retries the union `reqwest::Error::is_connect() || is_timeout()` and
  renders timeout before connect. With equal connect and request deadlines, native Windows may
  therefore report the same unavailable endpoint as `request timed out` without changing retry
  behavior.
- The compound test stopped at that wording assertion, masking its independent delayed-timeout
  and invalid-builder contracts.

## Acceptance criteria

- Give unavailable-endpoint, delayed-timeout, and invalid-builder behavior independent tests.
- Require an unavailable endpoint to return a typed network error, exactly three deterministic
  retry delays, terminal attempt `4/4`, a sanitized request context, and either normalized
  retryable transport detail.
- Keep delayed timeout exact and require all four attempts. Keep builder failure immediate,
  non-retried, and secret-free.
- Do not broaden production retryability, reorder production classification, or weaken redaction
  to force one platform's wording.
- Pass provider tests, the full workspace suite, exact Clippy, formatting, and native Windows CI.

## Verification

- Run the three focused provider tests and `cargo test -p depscan-providers --lib --locked`.
- Run `cargo test --workspace --all-targets --locked`.
- Run `cargo clippy --all-targets -- -D warnings`.

- Record a successful native Windows full-suite rerun before closing.

## Resolution and evidence (2026-08-20)

- The unavailable-endpoint regression now asserts the typed error, exact `200/400/800 ms`
  injected delays, terminal attempt, sanitized context, and the documented connect-or-timeout
  transport union. Credentials and query tokens are explicit redaction sentinels.
- Timeout and builder failures now run independently; timeout retains its exact message and retry
  count, while builder failure retains zero sleeps, attempt `1/4`, and secret removal.
- All three focused regressions pass, the provider library passes `129/129`, and the Rust 1.97.1
  workspace/all-target suite, exact all-target Clippy, formatting, and diff checks pass locally.
- DS-070 remains **In progress** until the corrected native Windows job passes.
