# DS-084: Consolidate duplicated OSV identity matching and package dedup

- **Status:** Open
- **Priority:** P2
- **Scope:** Cross-crate duplication with divergence risk

## Evidence

- The 2026-08-21 code review found byte-identical bodies in
  `affected_identity_matches` (`crates/depscan-core/src/osv.rs`) and
  `affected_matches_package` (`crates/depscan-providers/src/osv/scoring.rs`). Divergence here
  silently changes which advisories match a package.
- The `BTreeMap` + `merge_metadata` package dedup algorithm exists twice:
  `dedup` (`crates/depscan-parsers/src/lib.rs`) and `dedup_packages`
  (`crates/depscan-cli/src/app/policy.rs`).

## Acceptance criteria

- One owner per algorithm (the identity matcher belongs in `depscan-core`), with the second site
  reduced to a call.

## Verification

- Existing matcher and dedup tests pass unchanged.
- `bash scripts/dev-gate.sh full`
