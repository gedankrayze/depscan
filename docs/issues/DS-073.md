# DS-073: Modularize parser architecture and isolate parser tests

- **Status:** Closed
- **Priority:** P2
- **Scope:** `depscan-parsers` module ownership, file size, and test organization

## Evidence

- `crates/depscan-parsers/src/lib.rs` had grown to 7,694 lines and combined Node, Python,
  NuGet, and Cargo parsing with shared helpers and 1,702 lines of inline unit tests.
- The npm minimatch implementation was another 2,533-line production-and-test aggregation, while
  requirements parsing combined syntax, capability traversal, reading, diagnostics, and race tests.
- Large uv, Poetry, package-lock, Cargo-manifest, and Python-lock files further mixed record
  decoding, graph classification, manifest declarations, fixtures, and error matrices.

## Acceptance criteria

- Keep `lib.rs` as a small public façade without changing the crate's public parser API.
- Give each ecosystem and substantial parser concern a cohesive module boundary; split npm
  package-lock validation, minimatch compilation/matching, requirements capability traversal,
  Python lock records/graphs, and Cargo lock/manifests by responsibility.
- Move executable unit tests out of production files and split unit and integration suites by
  behavior while preserving test coverage and snapshot contents.
- Keep every parser Rust file at or below 400 lines, with any future exception explicit and
  reviewed.
- Pass the parser and workspace all-target suites, exact Clippy, formatting, and diff checks.

## Verification

- Run `cargo +1.97.1 test -p depscan-parsers --all-targets --locked`.
- Run `cargo +1.97.1 test --workspace --all-targets --locked`.
- Run `cargo clippy --all-targets -- -D warnings`.
- Run `cargo fmt --all -- --check` and `git diff --check`.
- Audit every Rust file below `crates/depscan-parsers` and reject files over 400 lines.

## Resolution and evidence (2026-08-20)

- `lib.rs` is now a 192-line façade. Node, Python, NuGet, and Cargo implementations have explicit
  ecosystem modules, with further ownership boundaries for npm/Bun/Yarn, Cargo workspace and lock
  graph behavior, NuGet XML models/readers, and Python lock formats.
- npm package-lock link and installed-entry validation, minimatch parsing/lowering/matching/classes,
  requirements syntax/traversal/reading/diagnostics, uv record/graph behavior, and Poetry manifest
  declarations now live in focused modules.
- Unit tests moved into domain suites under `src/tests/`, `npm_minimatch/tests/`, and
  `requirements/tests/`. The Cargo-manifest and Python-lock integration harnesses were split into
  focused modules without changing their stored snapshots.
- The crate now contains 107 Rust files; the largest is 384 lines and no file needs an exception to
  the 400-line ceiling. The full parser all-target suite passes, including all 74 unit tests and all
  integration harnesses. The Rust 1.97.1 workspace/all-target suite, exact all-target Clippy,
  formatting, and diff checks pass.
