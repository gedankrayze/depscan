# DS-044: Strengthen CLI help and typed value parsing

- **Status:** Open
- **Priority:** P1
- **Scope:** CLI usability / early validation

## Evidence

- Most arguments at `crates/depscan-cli/src/main.rs:48-90` have no doc comments/help text and use raw `String` values.
- Ecosystems, thresholds, formats, and durations are validated manually only after Clap parsing at `crates/depscan-cli/src/main.rs:355-402`, so shell completion/help cannot advertise allowed values and error behavior is inconsistent.
- Conflicts and requirements between offline/cache/output/log options are not expressed in the command model.

## Acceptance criteria

- Use typed Clap value enums/parsers for ecosystems, formats, thresholds, durations, and other closed sets, with correct value names and actionable errors.
- Provide concise help and long help describing defaults, repeatability, precedence, security implications, output/exit behavior, and best-effort ecosystem limits.
- Encode genuine conflicts/requirements in Clap and keep usage/config failures mapped to code `10` under DS-019.
- Generated completions include the allowed values.

## Verification

- Snapshot top-level/subcommand help and completions for representative shells.
- Add process tests for every invalid value, conflict, repeatable option, inferred format, and help/version exit.
