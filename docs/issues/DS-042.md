# DS-042: Make JSON output reproducible when requested

- **Status:** Open
- **Priority:** P1
- **Scope:** Core scan document / JSON contract

## Evidence

- `crates/depscan-core/src/lib.rs:246-258` assigns `generated_at = Utc::now()` inside `ScanDocument::new`.
- Identical scans therefore always produce byte-different JSON, complicating snapshots, caching, diff-based CI, and reproducible evidence.
- The clock is not injectable, so tests cannot control the value without post-processing.

## Acceptance criteria

- Inject scan time from orchestration and define a deterministic/reproducible mode (for example `SOURCE_DATE_EPOCH` or an explicit output option) while retaining useful timestamps by default.
- Sort all JSON collections whose order is not semantically meaningful.
- Document timestamp/timezone/schema semantics and preserve backward compatibility intentionally.

## Verification

- Run identical fixture scans twice in reproducible mode and assert byte-identical JSON.
- Add controlled-clock serialization tests and verify normal mode emits one valid UTC timestamp per scan.
