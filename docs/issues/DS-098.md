# DS-098: Adapt NuGet XML parsing to quick-xml 0.42

- **Status:** Closed
- **Priority:** P2
- **Scope:** NuGet XML parser compatibility and dependency maintenance

## Evidence

- Renovate PR #34 updates `quick-xml` from 0.41.0 to 0.42.0 but fails every native quality
  job, both static Linux jobs, and release quality during compilation.
- Version 0.42 represents XML names and event content as UTF-8 strings, removes
  `Reader::decoder()`, deprecates decoder-based attribute normalization, and makes
  `xml10_content()` infallible.
- The failures are confined to the NuGet XML adapter; the dependency's new Rust 1.86 MSRV is
  below depscan's Rust 1.96 policy.

## Acceptance criteria

- Upgrade the direct `quick-xml` dependency and locked package to 0.42.0.
- Use the string-based name, attribute-normalization, and event-content APIs without weakening
  duplicate-attribute detection, namespace-prefix handling, or XML error propagation.
- Add a regression that covers prefixed element/attribute names and normalized escaped attribute
  values, and retain the large duplicate-attribute and plain-reader namespace controls.
- Pass the parser all-target suite, architecture check, exact Clippy contract, and full workspace
  gate before integration into `develop`.

## Resolution

- Migrated qualified-name handling to quick-xml's UTF-8 string representation while preserving
  depscan's local-name extraction for prefixed NuGet elements and attributes.
- Replaced the deprecated decoder-based attribute API with `normalized_value()` and consumed
  infallible XML 1.0 text content directly. Duplicate attributes still fail through quick-xml's
  checked iterator, and normalization errors remain contextual parser errors.
- Added a prefixed NuGet project regression covering entity expansion and XML whitespace
  normalization; retained the large duplicate-attribute and plain-reader namespace regressions.

## Verification evidence

- The complete parser all-target suite passes: 143 tests across the unit and integration
  harnesses, including six NuGet unit tests with the new 0.42 compatibility regression.
- `bash scripts/dev-gate.sh full` passes locally under Rust 1.98.0: architecture and automation
  verifiers, formatting, exact `cargo clippy --all-targets -- -D warnings`, 434 workspace tests
  with one intentional live-provider ignore, GitHub Action and release-workflow verifiers, and
  `git diff --check` are green.
- `cargo +1.96.0 test --workspace --all-targets --locked` passes the same 434 tests plus one
  intentional live ignore at the workspace MSRV, and `cargo audit` finds no vulnerability among
  307 locked dependencies using 1,225 RustSec advisories.
- The Rust architecture check reports 250 Rust files, a 400-line maximum, and isolated test
  modules. Native protected-branch CI remains remote integration evidence rather than a local
  closure prerequisite.
