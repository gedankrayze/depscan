# DS-061: Preserve the verified GitHub Action executable identity

- **Status:** Closed
- **Priority:** P1
- **Scope:** Composite GitHub Action / release binary execution

_Closed-record excerpts; original dates and versions apply._

## Evidence

- `scripts/github-action/install-depscan.ps1` downloaded, checksum-verified, installed, and version-checked an absolute `depscan.exe`, but exported only its directory through `GITHUB_PATH`.

- `scripts/github-action/run-depscan.mjs` discarded that verified identity and spawned the bare name `depscan.exe` when the local-testing override was empty.

- Windows searches the parent process's current directory before `PATH` for an executable name without a directory path. GitHub Actions runs commands in the caller workspace, so a repository-controlled root `depscan.exe` could be selected instead of the verified release binary.

- The Unix path also discarded the installed identity even though its ordinary `PATH` search does not prioritize the current directory. Both platforms should preserve the same verified identity contract.

## Historical resolution

- The Unix and Windows installers now write `DEPSCAN_ACTION_INSTALLED_BINARY=<absolute path>` to `GITHUB_ENV` after checksum and version verification. They no longer append the install directory to `GITHUB_PATH`.

- The runner uses that absolute path only when the explicit override is empty. A relative or empty installed path fails before child execution; an explicit local path is still resolved absolutely and intentionally takes precedence.

- `verify-github-action.sh` now guards the environment handoff and absence of bare fallback literals. Its generated trusted, override, and decoy executables prove exact selection, literal metacharacter arguments, early typed-value rejection, and exit-status preservation.

- The Windows quality job now creates an inert workspace-root `depscan.exe`, invokes the wrapper with the built release binary's exact path, and requires the normal offline summary. The decoy is removed in a `finally` block and contains no executable code.

## Historical verification

- `bash scripts/verify-github-action.sh` passed, including installed-path, local-override, PATH-decoy, metacharacter, invalid-setting, and child-exit probes.

- `bash -n scripts/github-action/install-depscan.sh`, `node --check scripts/github-action/run-depscan.mjs`, ShellCheck, actionlint, and `git diff --check` passed.

- Native Windows job

  passed `Verify Windows action runner ignores a workspace executable decoy` after building the

  This supplies both the exact-path Windows evidence and the ordinary composite-action execution.

- No Rust source or dependency changed, so Rust formatting, Clippy, test, and MSRV gates were not required for this bounded action-wrapper fix.
