# DS-103: Coordinate Rust 1.99.1 across native, release, and static builds

- **Status:** Closed
- **Priority:** P2
- **Scope:** Toolchain configuration and CI policy

## Evidence

Renovate PR #59 only changes `rust-toolchain.toml`. Its Ubuntu run
`38790009924` fails `verify-ci-policy.sh` because four action pins still select
1.98.0. Release-quality commands and the static builder also still select 1.98.0;
the existing verifier does not check those two forms. The incomplete PR was closed
during the 2026-10-20 triage.

## Acceptance criteria

- Coordinate the channel, reviewed action SHA, release-quality commands, and pinned
  static Rust image at 1.99.1 while retaining the 1.96.0 MSRV.
- Make the policy verifier reject drift in the release commands and static image.
- Pass the release gate and test the policy verifier with deliberate mismatches.

## Resolution

- Coordinated Rust 1.99.1 across the toolchain file, all four stable action uses,
  release-quality commands, and the official digest-pinned Alpine builder image.
- Retained the supported Rust 1.96.0 floor. The README explicitly distinguishes
  that compatibility floor from the scheduled N-2 policy review target.
- Extended the CI verifier to inspect release commands and static-image pins.

## Verification

- The current policy verifier passes; isolated copies with a 1.98.0 release command
  or static image each fail with exit 1 and the corresponding drift diagnostic.
- The Rust 1.99.1 release gate passes, including exact Clippy, tests, five-crate
  packaging, and an optimized CLI build. Rust 1.96.0 passes the locked all-target
  suite on native macOS arm64. New hosted/native Linux and Windows evidence is
  pending publication of this local branch, not implied by these local checks.
