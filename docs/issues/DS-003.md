# DS-003: Preserve canonical NuGet names for OSV

- **Status:** Closed
- **Priority:** P0
- **Scope:** Core normalization / OSV provider / NuGet

## Evidence

- `crates/depscan-core/src/lib.rs:127-147` lowercases every NuGet package name at model construction time.
- `crates/depscan-providers/src/lib.rs:286-291` forwards that normalized name directly to OSV querybatch.
- Audit live evidence: OSV returned no advisory for `newtonsoft.json@12.0.1`, but returned `GHSA-5crp-9r3c-p9vr` for canonical `Newtonsoft.Json@12.0.1`.
- The lowercase form remains correct for NuGet's flat-container endpoint (`crates/depscan-providers/src/lib.rs:768-779`), so provider-specific identities must be separated.

## Acceptance criteria

- Preserve display/canonical NuGet casing in the package model and OSV request.
- Use lowercase only for NuGet registry URLs and case-insensitive internal lookup keys.
- Deduplication remains case-insensitive for NuGet packages.
- The development specification's normalization summary is corrected to distinguish OSV identity from registry URL normalization.

## Verification

- Add an OSV mock test that only returns `GHSA-5crp-9r3c-p9vr` for `Newtonsoft.Json@12.0.1`.
- Add NuGet registry tests proving the flat-container URL remains lowercase.
- Run a live opt-in OSV probe for the audited package and record the result.

## Resolution

- Kept the normalized NuGet package identity and result key lowercase while routing source-preserved casing into online OSV requests and their request-specific cache keys.
- Offline OSV matching now compares ecosystem-normalized identities; NuGet registry URL/cache helpers remain lowercase. Parser deduplication delegates to `Package::key()`.
- Added core, NuGet lock/XML, online OSV mock, offline ZIP, request/cache-key, and flat-container URL tests. `cargo +1.97.1 test --workspace --all-targets` passed 22 tests, and strict Clippy plus formatting checks passed on 2026-08-19.
- A live OSV batch probe returned no IDs for `newtonsoft.json@12.0.1` and `GHSA-5crp-9r3c-p9vr` for `Newtonsoft.Json@12.0.1`, confirming that the preserved request casing reaches the behavior under test.
- The repository README now documents internal, OSV, and registry name normalization separately.
