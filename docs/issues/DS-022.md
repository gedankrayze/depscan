# DS-022: Support the full CLI surface in configuration

- **Status:** Open
- **Priority:** P1
- **Scope:** CLI configuration

## Evidence

- `crates/depscan-cli/src/main.rs:48-84` defines the scan option surface.
- `crates/depscan-cli/src/main.rs:112-126` supports only the two failure thresholds and ignores.
- The specification requires every flag-settable scan option to be config-settable with command-line flags taking precedence.

## Acceptance criteria

- `depscan.toml` can express ecosystems, dev/direct filters, format/output, thresholds, offline/cache settings, withdrawn policy, ignores, tool permission, and log settings where meaningful.
- CLI values deterministically override config values, including booleans and repeatable lists.
- Unknown/mistyped config keys fail with exit `10` rather than being silently ignored.
- Defaults, merge rules, and security-sensitive `allow-tools` behavior are documented.

## Verification

- Add configuration deserialization and process tests for every field, default, CLI override, list merge/replace decision, unknown key, and invalid value.
- Snapshot `--help`/configuration documentation for parity.
