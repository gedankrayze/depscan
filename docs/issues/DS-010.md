# DS-010: Scan all .NET projects and central package versions

- **Status:** Open
- **Priority:** P1
- **Scope:** .NET detection and XML parsing

## Evidence

- `crates/depscan-parsers/src/lib.rs:579-593` selects only the first `*.csproj`/`*.fsproj`/`*.vbproj` and never detects `Directory.Packages.props`.
- `crates/depscan-parsers/src/lib.rs:624-670` can parse `PackageVersion` only when name and version occur in the same file/event; it does not merge central versions with versionless `PackageReference`s.

## Acceptance criteria

- Detect every project under the selected solution/root and the applicable nearest central props files.
- Merge central `PackageVersion` values with per-project `PackageReference` entries, including `Include`/`Update` and nested `Version` elements.
- Preserve per-project source provenance and deduplicate coordinates correctly.
- Continue to prioritize resolved `packages.lock.json` data where present without silently ignoring sibling projects.

## Verification

- Add multi-project fixtures covering C#/F#/VB, central package management, overrides, nested XML version elements, and multiple target frameworks.
- Assert every project/package pair is represented and the correct central override is selected.
