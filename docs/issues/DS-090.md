# DS-090: Initialize tracing before configuration resolution

- **Status:** Closed
- **Priority:** P2
- **Scope:** CLI diagnostics

## Evidence

- The 2026-08-21 code review found `run_scan` (`crates/depscan-cli/src/app/commands.rs`) calling
  `initialize_tracing` only after `prepare_scan`, so diagnostics emitted while resolving the
  config file are discarded; `config_origin.log()` exists as an explicit workaround to replay
  one of them.

## Acceptance criteria

- Tracing (or an equivalent early diagnostic path) is active during configuration resolution at
  a level consistent with `--quiet`/`--verbose`, and the replay workaround is removed. The
  wrinkle that verbosity flags themselves come from the parsed CLI (not the config) should make
  this straightforward; document the choice if config-derived verbosity is intentionally not
  supported.

## Verification

- An exit-code test asserting a config-resolution diagnostic reaches stderr under `--verbose`.
- `bash scripts/dev-gate.sh full`

## Resolution

- Tracing now initializes before configuration resolution with a reloadable `EnvFilter` at the
  CLI-flag level, so resolution-time diagnostics are captured live whenever the user asked for
  verbosity on the command line. The origin diagnostic is emitted inside `prepare_scan` as it
  happens.
- Config-set verbosity cannot apply retroactively; when the merged level differs from the CLI
  level (only possible when no CLI flag was given, meaning the live emission was filtered), the
  filter reloads and the single origin diagnostic is replayed — exactly one emission in every
  flag combination, preserving the existing `config_policy` contract test.
- Two new process-level tests lock the contract: `--verbose` surfaces "configuration file not
  found; using defaults" during resolution, and a config-set `verbose = 1` enables scan-phase
  debug diagnostics.

## Local verification evidence

- All CLI `--all-targets` suites pass (74 exit-code tests including the two new diagnostics
  tests and the pre-existing configured-verbosity contract test); workspace clippy is clean.
