# DS-043: Show yanked installed versions even when otherwise current

- **Status:** Open
- **Priority:** P1
- **Scope:** Table and summary reporting / freshness risk

## Evidence

- `crates/depscan-report/src/lib.rs:98-112` renders registry status only when `staleness > Current`.
- The `(installed version yanked)` annotation is nested inside that block, so an installed version equal to latest stable but yanked is hidden.
- Totals at `crates/depscan-report/src/lib.rs:271-279` likewise count only staleness, not yanked/deprecated installed releases.

## Acceptance criteria

- Render a prominent yanked/deprecated-installed warning regardless of staleness.
- Define whether yanked packages affect totals and failure policy, then implement consistently across table, JSON, SARIF, and summary.
- Do not label the latest release itself yanked when only the installed artifact/file is yanked.

## Verification

- Add renderer/process fixtures for yanked-current, yanked-outdated, partially yanked PyPI files, and non-yanked current versions across all formats.
