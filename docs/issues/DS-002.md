# DS-002: Replace approximate CVSS scoring

- **Status:** Closed
- **Priority:** P0
- **Scope:** Providers / vulnerability severity / CI exit behavior

## Evidence

- `crates/depscan-providers/src/lib.rs:418-426` selects the first severity score without preferring CVSS v4 over v3.
- The same code only reads top-level `severity[]`; OSV records may carry relevant ecosystem severity under `affected[].ecosystem_specific`/`affected[].database_specific` or affected-entry severity data, so the current implementation can leave a scored finding `Unknown`.
- `crates/depscan-providers/src/lib.rs:476-509` assigns ad hoc weights instead of evaluating the CVSS standard.
- Audit runtime evidence: both `quick-xml` advisories were assigned score 6.5/Medium, while RustSec reported 7.5/High; the default `--fail-on high` self-scan therefore exited `0` despite two High advisories.

## Acceptance criteria

- Parse CVSS v4 vectors first, then CVSS v3 vectors, with a maintained standards-compliant crate.
- Apply a documented OSV severity precedence that includes applicable `affected[]` severity sources when top-level vectors are absent, and restrict affected-entry fallback to the matching package/ecosystem.
- Store the standard base score and map it to the correct severity band.
- Unsupported or malformed vectors become `Unknown`, never an invented score.
- Threshold exits use the corrected severity and cannot pass a High finding at the default threshold.

## Verification

- Add table-driven CVSS v3.0, v3.1, and v4 tests, including the two audited RustSec vectors, top-level-versus-affected precedence, and affected-only severity.
- Run the self-scan fixture with `--fail-on high` and assert exit code `1`.
- Run `cargo test --workspace --all-targets` and `cargo clippy --all-targets -- -D warnings`.

## Resolution

- Added RustSec `cvss` 2.2.0 with explicit CVSS v3/v4 support. OSV scoring now prefers the highest valid v4 vector, falls back to the highest valid v3 vector, and consults only matching `affected[].severity` entries when top-level severity is unavailable.
- Added regression coverage for CVSS 3.0, 3.1, and 4.0; version preference; source-order independence; malformed/type-mismatched vectors; and package-scoped severity fallback.
- `cargo +1.97.1 fmt --all -- --check`, `cargo +1.97.1 test --workspace --all-targets` (13 tests), and `cargo +1.97.1 clippy --all-targets -- -D warnings` passed on 2026-08-19.
- A fresh-cache self-scan with `--fail-on high` exited `1` and reported both `RUSTSEC-2026-0194` and `RUSTSEC-2026-0195` as score `7.5`, severity `high`.
