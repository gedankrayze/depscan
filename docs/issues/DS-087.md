# DS-087: Remove dead public API and the duplicate ecosystem alias table

- **Status:** Open
- **Priority:** P2
- **Scope:** Dead and duplicated API surface

## Evidence

- The 2026-08-21 code review found `Cache::put` (`crates/depscan-providers/src/cache/store.rs`)
  used only by tests, `OutputFormat::parse` (`crates/depscan-report/src/lib.rs`) used only by
  its own tests, and `Ecosystem::from_cli` (`crates/depscan-core/src/ecosystem.rs`) used only by
  provider test support while the CLI maintains the same alias table separately in clap's
  `EcosystemArg`. `Ecosystem::osv_name` and `display_name` return identical strings for every
  variant, and `crates/depscan-parsers/src/lib.rs` has a pure-alias `source` -> `candidate`
  forwarding function.
- `pub` items with only internal callers: `HttpClient::get_json`/`post_json`
  (`crates/depscan-providers/src/http/client.rs`) whose siblings are already `pub(crate)`.

## Acceptance criteria

- Dead public items are removed or demoted before the next publication (removal is
  semver-major, so it should ride with DS-083); one alias table remains with one owner; the
  `osv_name`/`display_name` distinction is either made real or collapsed.

## Verification

- `cargo package --workspace --locked` and the full workspace test suite.
- `bash scripts/dev-gate.sh full`
