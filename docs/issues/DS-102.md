# DS-102: Prepare the v2.0.2 dependency-maintenance release

- **Status:** Closed
- **Priority:** P1
- **Scope:** Workspace dependency updates, release-version contract, and protected-main publication

## Evidence

- The latest public release is immutable `v2.0.1` at protected-main commit
  `ed44b12bde0fe906fc868cca04971024f7e6aeab`.
- `develop` contains the processed dependency updates for `toml`, `reqwest`, `clap`,
  `clap_complete`, `js-semver`, and `noyalib` that are not present in `v2.0.1`.
- Live preflight found no remote `v2.0.2` tag or GitHub release. The repository's publication
  contract distributes GitHub release binaries and does not currently publish a `depscan-cli`
  crate on crates.io.

## Acceptance criteria

- The workspace and all four internal dependency requirements use `2.0.2`, and the lockfile
  records that version for all five workspace packages.
- The composite action, README examples, installer diagnostics, Markdown attribution test, and
  tag-bound release acceptance workflow use `2.0.2`/`v2.0.2` consistently.
- The release workflow verifier derives the expected acceptance tag from the workspace version
  and continues to enforce the reviewed immutable 16-file release contract.
- The release workflow verifier, cargo-dist generation check, reviewed asset plan, and
  `bash scripts/dev-gate.sh release` pass on the complete candidate tree.
- Publication targets the reviewed protected-main commit only after protected CI and the
  incoming-PR gate pass. Tag, release, asset, attestation, and native acceptance evidence are
  verified after publication rather than claimed during preparation.

## Resolution

- Aligned the workspace, internal crate requirements, five lockfile package records, composite
  action, README download/action examples, installer diagnostics, Markdown attribution test, and
  release-acceptance workflow to `2.0.2`/`v2.0.2`.
- The dependency update PRs were processed and merged into `develop`; the replacement `noyalib`
  PR was fully gated after the original lockfile-conflicting update was superseded.
- Local release gates and protected-main publication remain required post-preparation evidence.
