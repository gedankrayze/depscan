# DS-063: Support suffix-aware npm extglobs safely

- **Status:** Open
- **Priority:** P1
- **Scope:** npm workspace minimatch compatibility

## Evidence

- npm 11 accepts a version 3 lock whose root workspace pattern is `packages/pre!(bad).js` and emits the `packages/pregood.js` descriptor plus its link.
- The bounded Rust workspace matcher deliberately rejects a negative extglob combined with prefix or suffix tokens because a local span-only implementation can incorrectly prove attacker-selected paths as workspaces. For example, npm does not match `packages/ac` against `packages/!(a)*`, while a naive negative-token matcher does.
- Positive extglobs also have suffix-sensitive wildcard behavior: npm does not match `packages/a` against `packages/*@(a|b)` because the standalone `*` becomes non-nullable next to the extglob. A nullable local wildcard would falsely prove that path as a workspace, so DS-057 rejects sequences that combine standalone stars and extglobs.
- DS-057 therefore fails this valid lock closed with exit `10`; it does not silently hide a registry dependency, but the project cannot be scanned until the pattern is supported or rewritten.

## Acceptance criteria

- Implement suffix/remainder-aware positive and negative extglob matching compatible with npm minimatch for prefixed, suffixed, standalone-star, repeated-wildcard, nested, and empty-alternative boundaries.
- Preserve the existing pattern, candidate, expansion, nesting, AST, and match-operation limits; exhausting a bound must remain a parse error.
- Do not broaden cross-component extglobs or any unsupported syntax into a positive workspace match.
- Parse real npm-generated mixed-negative-extglob workspace locks without weakening the forged-link protections from DS-057.

## Verification

- Differential-test a bounded corpus against npm's bundled minimatch, including `pre!(bad).js`, `!(a)*`, `!(a)b`, `a!(b)c`, `*@(a|b)`, `@(a|b)*`, alternatives, nullable suffixes, and nested forms.
- Add a real npm 11 workspace fixture and a forged-link negative control proving valid descriptors are accepted while a nonmatching target exits `10`.
- Run the full workspace suite on Rust stable and MSRV plus exact Clippy.
