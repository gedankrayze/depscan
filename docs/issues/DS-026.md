# DS-026: Upgrade direct dependencies to current stable releases

- **Status:** Closed
- **Priority:** P1
- **Scope:** Dependency freshness / API migration

## Evidence

- Workspace constraints are recorded at `Cargo.toml:19-44`; audited locked versions include `directories` 5.0.1 (`Cargo.lock:556-557`), `rand` 0.8.7 (`1461-1462`), `reqwest` 0.12.28 (`1557-1558`), `sha2` 0.10.9 (`1783-1784`), `toml` 0.8.23 (`2059-2060`), `thiserror` 1.0.69 (`1916-1917`), `quick-xml` 0.36.2 (`1374-1375`), and `zip` 2.4.2 (`2821-2822`).
- Audit latest-stable evidence as of 2026-08-19: `directories` 6.0.0, `rand` 0.10.2, `reqwest` 0.13.4, `sha2` 0.11.0, `toml` 1.1.4+spec-1.1.0, `thiserror` 2.0.20, `quick-xml` 0.41.0, and `zip` 8.6.0.
- A disposable migration passed all eight existing tests, strict Clippy, Rust 1.97.1/1.95.0 checks, and `cargo audit` after adapting Reqwest TLS features, Rand APIs, SHA-2 hex encoding, and TOML parsing.

## Acceptance criteria

- Refresh every direct normal/dev/build dependency against current crates.io stable releases and upgrade all outdated constraints intentionally.
- Complete breaking API migrations without compatibility shims that weaken correctness or security.
- Preserve rustls-only networking and the declared MSRV; document any dependency intentionally held back with owner/reason/review date.
- Regenerate and commit `Cargo.lock` with no known advisories.

## Verification

- Re-run an authoritative dependency freshness tool/query at implementation time and attach its output.
- Run `cargo update`, `cargo tree -d`, `cargo audit`, both toolchain gates from DS-025, all tests, and strict Clippy.
- Exercise live/mocked OSV, registry, cache, sync, and report smoke paths after the major upgrades.

## Resolution

- Refreshed all 29 unique direct crates from the crates.io API on 2026-08-19, using each crate's `max_stable_version` and the matching release's declared `rust_version`. `cargo upgrade --dry-run --incompatible allow --rust-version 1.95.0 --verbose` independently reported `latest: 29 packages` and `local: 4 packages`; no direct registry dependency is held back.

- Migrated Rand to `rng().random_range`, encoded SHA-256 cache keys explicitly as lowercase hexadecimal, and changed all whole-document TOML reads to `toml::from_str`. Reqwest remains `default-features = false` with only the Rustls TLS backend; the feature tree contains `hyper-rustls`, `tokio-rustls`, and `rustls-platform-verifier`, with no native-TLS/OpenSSL backend. Zip is restricted to its Deflate feature rather than its broad defaults.
- `serde_yaml` is already at its latest published release, `0.9.34+deprecated`; replacement of that unmaintained crate remains isolated in DS-027.
- `cargo update` resolved 274 dependencies at versions compatible with Rust 1.95.0. `cargo tree -d` reports only the expected transitive `syn` 2/3 split. A freshly fetched RustSec database reported zero vulnerabilities.
- On Rust 1.97.1, formatting, all 84 tests, exact strict Clippy, and the locked release build passed. On Rust 1.95.0, the locked all-target check and all 84 tests passed.

A fresh-cache live scan queried OSV and the crates.io sparse index over Rustls, reported `serde` 1.0.229 as the latest release, and rendered JSON successfully; an immediate repeat used the cache without network access. Live `sync --ecosystem cargo` downloaded the 3,376,851-byte OSV archive, and an offline scan reopened that Zip 8 archive and rendered a clean summary.
