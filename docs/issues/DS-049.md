# DS-049: Deliver the M6 composite GitHub Action

- **Status:** Closed
- **Priority:** P2
- **Scope:** GitHub Actions / release distribution

_Closed-record excerpts; original dates and versions apply._

## Evidence

- Development specification milestone M6 explicitly includes a thin composite GitHub Action; the repository had no root `action.yml` or `action.yaml`.

- The specification's open question chooses only whether the wrapper lives in this repository or a separate one, not whether M6 delivers it.

- A wrapper that accepts a free-form argument string or executes an unverified download would add a CI command-injection or release-integrity boundary.

## Historical resolution

- Added root `action.yml` with typed path, ecosystem, format, output, failure-threshold, cache, filtering, and offline inputs. Input values enter fixed environment variables and `run-depscan.mjs` builds a child-process argument array with `shell: false`; no arbitrary argument or tool-execution input exists.

- Added closed Unix and Windows installer matrices for the five release targets. Both require an exact `vMAJOR.MINOR.PATCH` tag, validate a one-record checksum file naming the selected archive, verify the archive against that release checksum before extraction, verify the embedded CLI version, and export the exact verified executable through `DEPSCAN_ACTION_INSTALLED_BINARY` in `GITHUB_ENV`.

- Added an Ubuntu `uses: ./` CI smoke that supplies the locally built release binary, creates a valid offline Cargo fixture cache, runs the composite action, and verifies the produced summary.

## Historical verification

- Immutable tag-dispatched acceptance run
  [32382623588](https://github.com/gedankrayze/depscan/actions/runs/32382623588) passed on all five
  supported native runners: macOS x86-64 `96469635763`, Linux x86-64 `96469635920`, Linux ARM64
  `96469635949`, macOS ARM64 `96469635978`, and Windows x86-64 `96469635989`.

- Every job invoked the action from the immutable checked-out v1.2.0 source without a `binary`
  override, downloaded the public target archive, verified the paired checksum and tag-bound
  attestation, proved byte identity with the independently authenticated archive, reported the
  exact installed version, and produced the expected four-package offline summary.
