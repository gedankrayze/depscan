# DS-104: Remove newly disclosed RustSec findings and adapt the ZIP 9 reader

- **Status:** Closed
- **Priority:** P1
- **Scope:** Dependency security and offline OSV archive validation

## Evidence

The 2026-10-20 audit reports ten findings: quinn-proto 0.11.17
(RUSTSEC-2026-0338, -0340, -0343), rustls 0.23.45 (-0346 through -0349),
and zip 8.6.0 (-0367 through -0369). Patched floors are quinn-proto 0.11.18,
rustls 0.23.46, and zip 9.0.0. This is lockfile evidence; it does not mean
every optional transport or extraction API is used by DepScan.

PR #64 fails compilation in run `39069237153`: ZIP 9's `ZipFile::name()`
returns `Result<Cow<str>, ZipError>`. It was closed for a coordinated migration.
ZIP 9 also refuses data exceeding declared sizes, so the forged-size regression
must accept this earlier rejection without weakening the size checks.

## Acceptance criteria

- Upgrade to patched compatible versions without advisory exemptions.
- Propagate invalid archive-name errors with archive/entry context.
- Retain declared/actual decompression budgets and reject forged or invalid names.
- Pass provider regressions and a fresh `cargo audit` with no findings or warnings.

## Resolution

- Upgraded ZIP to 9.0.5, rustls to 0.23.46, and quinn-proto to 0.11.18,
  without adding advisory exemptions or enabling ZIP's unrelated default features.
- Adapted the fallible ZIP name API with contextual error propagation. Added a
  decoded-name/advisory-ID mismatch control. ZIP may decode non-UTF-8 names as
  CP437; the identity check still rejects a name that cannot match the advisory.
- Existing forged-size tests accept ZIP 9's specific earlier declared-size
  rejection as well as DepScan's explicit actual-size rejection; entry, aggregate,
  count, download, and publication bounds remain enforced.

## Verification

- All 139 provider unit tests pass, including offline reads, size budgets,
  interrupted transfers, capability races, rollback, and publication tests.
- A fresh `cargo audit --json` reports zero vulnerabilities and zero warnings.
- The release gate and retained-MSRV suite pass; no release or tag was published.
