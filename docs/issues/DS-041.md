# DS-041: Error when an explicitly requested config file is missing

- **Status:** Open
- **Priority:** P1
- **Scope:** CLI configuration discovery

## Evidence

- `crates/depscan-cli/src/main.rs:344-350` returns default configuration whenever the selected path does not exist.
- This treats an explicit `--config /path/to/missing.toml` the same as an absent implicit root `depscan.toml`, silently dropping the user's intended security thresholds and ignores.

## Acceptance criteria

- Absence of the implicit default config remains allowed.
- An explicit `--config` that is missing, inaccessible, not a regular file, or unsafe to read returns a usage/config error (`10`) naming the path.
- Configuration origin is available in verbose diagnostics.

## Verification

- Add process tests for absent implicit config, missing explicit config, directory path, permission/read failure, symlink policy, and valid explicit config.
