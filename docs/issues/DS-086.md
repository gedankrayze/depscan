# DS-086: Prune unused and misplaced dependency declarations

- **Status:** Open
- **Priority:** P2
- **Scope:** Crate manifests

## Evidence

- The 2026-08-21 code review found `anyhow` declared by `crates/depscan-cli/Cargo.toml` with
  zero occurrences anywhere in the workspace; `thiserror` declared by `depscan-parsers` and
  `depscan-providers` with zero occurrences in their sources; `tempfile` in
  `[dependencies]` of `depscan-providers` though used only under `src/tests/`; and `tempfile`
  listed in both `[dependencies]` and `[dev-dependencies]` of `depscan-cli`.

## Acceptance criteria

- Unused declarations are removed and test-only dependencies live in `[dev-dependencies]`.
  Note: `src/tests/` modules compile with the library, so `depscan-providers` either moves the
  usage or documents why `tempfile` stays a regular dependency (`#[cfg(test)]` gating keeps it
  out of release binaries either way).
- Optionally, `cargo machete` or `cargo +nightly udeps` joins a quality gate to keep this true.

## Verification

- `cargo build --release --locked -p depscan-cli` and the full workspace test suite.
- `bash scripts/dev-gate.sh full`
