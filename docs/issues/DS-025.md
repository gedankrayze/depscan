# DS-025: Modernize the Rust toolchain, edition, resolver, and MSRV policy

- **Status:** Closed
- **Priority:** P1
- **Scope:** Rust build policy / CI

## Evidence

- `Cargo.toml:9` uses resolver 2, `Cargo.toml:13` uses Edition 2021, and `Cargo.toml:16` declares Rust 1.75.
- No `rust-toolchain.toml` was present in the audited repository.
- `.github/workflows/ci.yml:20-23` follows floating `stable`, while lines `35-42` run an exact 1.75 job.
- Audit evidence as of 2026-08-19: latest stable was Rust 1.97.1; the exact 1.75 CI command failed because locked dependencies require Edition 2024 support. The agreed N-2 support floor was 1.95.0.

## Acceptance criteria

- Pin the development/release toolchain to the latest verified stable patch (1.97.1 at audit time, refreshed before implementation).
- Migrate to Edition 2024 and workspace resolver 3.
- Set `rust-version` to the explicitly supported MSRV (1.95.0 for the audited N-2 policy), not to the toolchain pin.
- CI tests the pinned stable toolchain and actual MSRV, and dependency resolution remains MSRV-compatible.
- Document the stable/MSRV update policy and refresh cadence.

## Verification

- Run format, tests, strict Clippy, and release build on the pinned stable toolchain.
- Run `cargo +1.95.0 check --workspace --all-targets` and tests required by the MSRV policy.
- Confirm `cargo metadata` reports Edition 2024/resolver 3 and the intended `rust_version` for every workspace crate.

## Resolution

- Added `rust-toolchain.toml` pinned to Rust 1.97.1, the version published by the official stable channel manifest on 2026-08-19, with Rustfmt and Clippy components.
- Migrated every workspace crate to Edition 2024, resolver 3, and explicit MSRV 1.95.0. CI now uses the pinned stable patch and runs check plus tests on the N−2 MSRV.
- Documented the stable/MSRV refresh policy in the README and updated the development commands to the required all-target gates.
- On Rust 1.97.1, formatting, all 31 tests, exact strict Clippy, and the locked release build passed. On Rust 1.95.0, locked all-target check and all 31 tests passed.
- `cargo metadata` reported Edition 2024 and `rust_version` 1.95.0 for all five crates; the workspace manifest reports resolver 3. `actionlint` also passed for the updated workflow.
