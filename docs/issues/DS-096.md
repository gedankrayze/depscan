# DS-096: Coordinate the Rust 1.98.0 toolchain and 1.96.0 MSRV refresh

- **Status:** In progress — native macOS is green; protected Linux and Windows matrix evidence remains pending
- **Priority:** P2
- **Scope:** Toolchain policy refresh

## Evidence

- Renovate PR #28 bumped `rust-toolchain.toml` to 1.98.0 in isolation and failed the quality
  matrix on all three platforms: the workflow pins still installed 1.97.1, and Rust 1.98's
  sharper unused-import lints turned two provider test imports into `-D warnings` errors. The
  repository's documented policy requires the coordinated refresh: pin the new stable, move
  the MSRV to N−2, update CI, and verify both toolchains.

## Acceptance criteria

- One change updates the toolchain channel, the MSRV, every workflow pin (enforced by the
  DS-094 verifier), the static-Linux builder image, the release-quality invocations, and the
  documentation, with both toolchains verified locally.

## Verification

- `bash scripts/dev-gate.sh full` on 1.98.0; `cargo +1.96.0 check`/`test --workspace
  --all-targets --locked` for the MSRV; `scripts/verify-ci-policy.sh`.

## Resolution

- Pinned stable 1.98.0 everywhere: `rust-toolchain.toml`, the `dtolnay/rust-toolchain` commits
  in CI, live-provider-smoke, and dependency-audit (SHA resolved from the action's own 1.98.0
  tag), the six `release-quality.yml` invocations, and the static-Linux `rust:1.98.0-alpine`
  image by its Docker Hub digest. MSRV moved to 1.96.0 (`Cargo.toml` `rust-version`, the CI
  MSRV job pin, docs). README and the test matrix reflect the new pair.
- Removed the two imports Rust 1.98 newly flags (`super::osv::*` glob and the unused
  `AsyncWriteExt` alias in the provider test root), keeping `clippy -D warnings` clean.
- Supersedes Renovate PR #28, which is closed in favor of this coordinated change.

## Local verification evidence

- Full dev-gate passes under 1.98.0 (all 21 workspace suites, strict clippy, verifiers);
  `cargo +1.96.0 check` and the full `--locked` test suite pass on the new MSRV (21 suites,
  zero failures). `verify-ci-policy.sh` confirms every workflow pin matches the new channel or
  MSRV. Native evidence is macOS; the cross-platform matrix runs on the pushed commit.
- An independent 2026-08-21 rerun again passed the full 1.98.0 dev gate and the complete
  1.96.0 workspace/all-target test suite on macOS. GitHub has no run attached to develop head
  `5fc4e519d630dac4503ca8e57d6dc19561cb2f99`; Ubuntu and Windows remain external evidence.
