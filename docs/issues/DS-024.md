# DS-024: Make workspace crates publishable

- **Status:** Open
- **Priority:** P1
- **Scope:** Cargo packaging / `cargo install`

## Evidence

- `crates/depscan-cli/Cargo.toml:14-17`, `crates/depscan-parsers/Cargo.toml:10`, and `crates/depscan-providers/Cargo.toml:10` declare internal path dependencies without a version.
- Audit runtime evidence: `cargo package` failed because publishable path dependencies require version metadata.
- The specification promises a `cargo install` path.

## Acceptance criteria

- Every published internal dependency declares a compatible version alongside `path`, or non-published crate boundaries are redesigned intentionally.
- Package include/exclude metadata ships all required README/license/source assets and no local/generated artifacts.
- A clean packaged CLI can resolve only registry artifacts and install successfully.

## Verification

- Run `cargo package --workspace` (or the documented publishable subset) with verification enabled.
- Inspect each `.crate` file list and install the packaged CLI into a temporary `CARGO_HOME` without workspace path access.
- Run the installed binary's `--help` and a fixture smoke scan.
