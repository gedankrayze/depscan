# DS-020: Render included withdrawn advisories consistently

- **Status:** Closed
- **Priority:** P1
- **Scope:** CLI/report contract

## Evidence

- `crates/depscan-cli/src/main.rs:258-260` retains withdrawn advisories when `--include-withdrawn` is set, and threshold evaluation at `404-418` includes all retained vulnerabilities.
- Table, summary, SARIF, sorting, and totals independently filter withdrawn advisories at `crates/depscan-report/src/lib.rs:76`, `129`, `191`, `240`, and `263-269`.
- The command can therefore fail on a finding hidden from its human and SARIF output.

## Acceptance criteria

- `--include-withdrawn` controls one consistent model used by thresholding and every renderer.
- Included withdrawn advisories are visibly labeled as withdrawn in table, JSON, SARIF, and summary/totals.
- Without the flag, withdrawn advisories neither render nor affect exits.

## Verification

- Add renderer and process-level tests for the same withdrawn fixture with and without the flag across all four formats.
- Assert visible counts, labels, SARIF results, and exit codes agree.

## Resolution

- CLI filtering is now the single inclusion boundary: without `--include-withdrawn`, withdrawn advisories are removed before thresholding and rendering; with it, they remain in the shared scan document.
- Renderers no longer silently filter the model. Retained advisories receive a `[WITHDRAWN]` table label, the existing JSON boolean, a SARIF `withdrawn` property and message label, plus explicit summary/table totals.
- Included withdrawn advisories retain their severity and therefore affect `--fail-on` exactly when they are visible. Active advisories are never given the withdrawn label.
- README documentation states the default exclusion and the opt-in rendering/exit behavior.

## Verification evidence

- One process fixture ran with and without `--include-withdrawn` across table, JSON, SARIF, and summary, asserting matching visibility and exits (`0` excluded, `1` included at High).
- Renderer tests assert labels, SARIF properties, summary counts, totals, and active-advisory behavior.
