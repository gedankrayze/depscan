# DS-091: Schedule advisory scanning of depscan's own dependency tree

- **Status:** Closed
- **Priority:** P1
- **Scope:** Supply-chain monitoring for this repository

## Evidence

- The 2026-08-21 review found no automated advisory scanning of depscan's own dependencies: CI
  has no `cargo audit`/`cargo deny` job, the dogfood self-scan runs offline against cached
  fixtures, the weekly live smoke exercises provider APIs rather than this workspace's
  dependency tree, and `renovate.json` explicitly disables `vulnerabilityAlerts`.
- A manual `cargo audit` on 2026-08-21 was clean (1225 advisories loaded, 307 locked crates, no
  findings), so this is a monitoring gap, not a current exposure.

## Acceptance criteria

- A scheduled read-only workflow (weekly, alongside the live provider smoke) fails on new
  RustSec advisories against the locked dependency tree — via `cargo audit`, or by
  dogfooding a live `depscan scan` of this workspace, keeping the tool as its own first user.
- Renovate `vulnerabilityAlerts` is re-enabled or the reason for disabling it is documented next
  to the setting.

## Verification

- Dispatch the new workflow manually once and record the green run; confirm a deliberately
  pinned old advisory-triggering version fails it in a branch experiment.

## Resolution

- Added `.github/workflows/dependency-audit.yml`: a weekly (Monday, offset from the provider
  smoke) read-only workflow with two jobs — `cargo audit` over the locked tree via a
  freshly-installed cargo-audit, and a live depscan self-scan of this workspace
  (`--ecosystem cargo --fail-on high`), keeping the tool its own first user. Actions are
  SHA-pinned with `persist-credentials: false`, matching house style.
- Re-enabled Renovate `vulnerabilityAlerts` by removing the explicit disable.

## Local verification evidence

- The self-scan step ran locally verbatim against live registries and OSV: 307 workspace
  packages, 0 vulnerabilities, exit 0. A manual `cargo audit` on 2026-08-21 was clean (1225
  advisories, 307 locked crates). Workflow YAML parses; `renovate.json` remains valid JSON.
